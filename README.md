# Hi, I'm Patrick

I build small, self-running automations: GitHub Actions instead of servers,
Markdown instead of databases, and n8n workflows that are documented well
enough to reuse. Most of it starts as a tool I needed myself.

## Projects

| | What it does | |
|---|---|---|
| **[notebooklm-github-sync](https://github.com/patrick-creates/notebooklm-github-sync)** | Syncs your repo's Markdown docs to Google NotebookLM on every push. Composite Action, no Google Cloud. | `uses: patrick-creates/notebooklm-github-sync@v1` |
| **[rising-repos-tracker](https://github.com/patrick-creates/rising-repos-tracker)** | Daily star and fork history for fast-growing repos, weekly report, live dashboard. No server, no database. | [Dashboard](https://patrick-creates.github.io/rising-repos-tracker/) |
| **[anthropic-news-monitor](https://github.com/patrick-creates/anthropic-news-monitor)** | Unofficial daily monitor of the Anthropic newsroom: categories, RSS feed, dashboard. Fork it, no keys needed. | [Dashboard](https://patrick-creates.github.io/anthropic-news-monitor/) · [RSS](https://patrick-creates.github.io/anthropic-news-monitor/feed.xml) |
| **[telosignal-workflow-vault](https://github.com/patrick-creates/telosignal-workflow-vault)** | Documented n8n workflow templates, incl. a benchmark for the Guardrails node, plus an MCP server that reviews workflows. | |
